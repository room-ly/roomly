# Roomly コンテンツ戦略・記事執筆

## 記事戦略（SEO優先度）

### 優先すべき記事テーマ
1. **苦情・トラブル対応系**（水漏れ、ゴミ出し、設備故障） — 検索ボリューム大、管理会社スタッフにも直接刺さる
2. **家賃滞納・督促系**（滞納初動、督促状の書き方、保証会社の使い方） — 切実な悩み、ボリューム大
3. **自主管理大家のストレス系**（自主管理きつい、夜間対応、修繕対応遅い） — 競合が個人ブログ中心で狙いやすい
4. **管理委託の判断系**（自主管理の限界、委託費用の相場） — CVに最も近い。悩み系記事からの内部リンク先として後から書く

### 後回しでいい記事テーマ
- **市場動向・時事系**は月1本程度に抑える。バズ可能性はあるが「賃貸管理」のドメイン専門性を積み上げにくい

## 記事作成ワークフロー（3ステップ）

テーマ → 切り口 → 執筆を明確に分離する。いきなり書き始めない。

**Step 1: 切り口ブレスト（必須・執筆前にユーザー確認）**
- テーマに対して「読者が "え？" と思う切り口」を5〜10案出す
- ありきたりな正論は除外。逆説的・意外性のあるものだけ残す
- 技法: 問いの逆転 / 他業界からの輸入 / 具体の一夜 / データファースト / 視点の転換 / 正解を言わない / 具体ストーリー
- **ユーザーが選んだ案が確定するまで執筆しない**

**Step 2: 具体 ↔ 抽象の設計**
- **具体（入口）**: 読者が「あるある」と思える場面描写
- **抽象（本質）**: より深い構造・問いで「なるほど」と思わせる
- 具体 → 抽象の順で書く（逆にしない）
- **具体と抽象はなるべく「遠い」ところを行き来する**: 「水漏れ → 情報の空白が怒りを生む心理構造」のように日常の事象から別の領域の本質へ飛ぶ
- **比喩・比較は「遠い業界・領域」から持ち込む**: 航空・医療・軍事・生態学・行動経済学・歴史・建築・SaaS運営など

**Step 3: 執筆**
- Step 1-2で方向が決まってから書き始める
- 毎回同じ構成（問題提起→なぜダメか→代替案→まとめ）にしない

**トリガー別の開始ステップ:**
- ユーザーがテーマだけ指定 → Step 1（切り口ブレスト）から
- 切り口まで指定 → Step 2（具体と抽象の設計）から
- 具体と抽象まで指定 → Step 3（執筆）から

## エゴサ引っかけ戦略（実名引用による認知獲得）

記事内で **Roomlyの顧客・パートナーになりうる人や企業の実名をポジティブに引用** し、エゴサーチで記事を発見 → Roomlyを認知する導線を意識的に作る。

### 重要: AI単独での実名引用は禁止

**AI(Claude)が自律的に実名引用を入れることは禁止する。** 過去に「○○氏の解説によると」と書きながら裏取りせず、本人が実際には言っていない内容を引用してしまう事故があった。これは信頼を失う方向に強く効くので、必ず以下のフローを守る:

1. **ユーザーが「ここに○○の引用を入れたい」と指示する**、または
2. **AIが「○○の引用を入れる候補がある」とユーザーに提案し、引用元のサイト/SNSをWebFetchで実際に読み、引用すべきフレーズや論点を特定したうえでユーザーが承認する**

裏取りなしで「○○氏も指摘するように」と書くのは禁止。一般論として書く方が安全。

### 基本ルール（人間レビューが入る場合のみ）
- **ポジティブな文脈でのみ引用する**（批判・比較はしない）
- **引用は自然な文脈で**（「〇〇の調査によると」「〇〇が詳しい」等）
- **個人〜小規模の専門家を狙う。** 名前を出されたら嬉しいと感じるサイズ感がベスト
- **引用前に必ず本人のサイト/SNSを読む。** 該当する発言・記事が本当にあるか確認する
