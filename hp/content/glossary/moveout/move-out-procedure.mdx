## 退去手続きの流れ

| 時期 | 対応 |
|------|------|
| 退去予告受領 | 受領日・退去予定日を記録 |
| 即時 | 募集開始、内見対応の準備 |
| 退去2週間前 | [退去立会い](/glossary/move-out-walkthrough)の日程調整 |
| 退去前日 | 借主に最終確認 |
| 退去当日 | 立会い・鍵返却 |
| 退去翌日〜 | [原状回復工事](/glossary/restoration-work)業者の手配 |
| 工事完了後 | [退去精算](/glossary/move-out-settlement)・[敷金返還](/glossary/security-deposit-return) |

## 借主との連絡項目

- 退去日の確定
- 鍵の返却方法・時期
- 公共料金の精算
- 郵便物の転送設定
- 引越し業者の搬出時間
- 立会い日時
- 敷金返還の振込先口座

## 退去時のチェック事項

- 退去日までの賃料精算
- 借主の私物撤去
- 残置物の有無
- 鍵・付属品の返却
- 室内の損耗状況
- 設備の動作確認

残置物が多いと、撤去費用が借主負担になります。

## 退去後すぐに行うこと

- 原状回復工事の見積もり
- ハウスクリーニング業者の手配
- 鍵交換
- 募集物件としての写真撮影
- 入居者募集の情報更新

退去日翌日から客付け開始できる体制が、空室期間短縮の鍵です。

## 大家・管理会社の実務ポイント

- 退去予告受領から募集開始まで1日以内
- 退去立会いを必ず実施（後日トラブル防止）
- 借主との連絡履歴を記録
- 工事業者・クリーニング業者の同時手配
- 敷金返還は契約書通りの期日で実施
- 賃貸管理ソフトで退去ワークフローを自動化
