## 共用部の範囲

- 廊下・階段
- エントランス・玄関ホール
- エレベーター
- 駐輪場・駐車場
- ゴミ置場
- 屋上・庭・植栽
- 集合郵便受け・宅配ボックス
- 外灯・共用照明

これらの維持管理費用は[共益費・管理費](/glossary/common-fee)から支払われます。

## 共用部の管理ルール

入居者が共用部を私物化しないよう、ルールを定めます。

- 廊下への私物放置禁止
- 玄関前への自転車駐輪禁止
- ベランダの過度な私物放置禁止
- 共用部での喫煙・飲食禁止
- ペットの抱きかかえ義務（廊下を歩かせない）

これらは契約書・入居案内に明記し、入居時に説明します。

## 共用部の清掃・点検

| 項目 | 頻度 |
|------|------|
| 共用廊下清掃 | 週1〜2回 |
| エントランス清掃 | 毎日〜週3回 |
| ゴミ置場清掃 | 収集日 |
| 共用照明点検 | 月1回 |
| 植栽手入れ | 月1〜2回 |
| 排水溝清掃 | 半年〜1年 |

清掃の質が物件全体の印象を左右します。

## 大家・管理会社の実務ポイント

- 共用部の状態は入居率に直結する
- 巡回時にチェックリストで状態を記録
- 私物放置の常習者には個別注意
- 防犯カメラの設置で違反抑止
- 大規模物件は専門清掃業者に委託
- 階段・廊下の電球切れは即日対応
- 共用部の修繕は迅速に対応（入居者の不満要因）
- 季節ごとの注意喚起ポスター（落ち葉・雪・虫等）
