## 業者の種類

| 業務 | 必要な提携業者 |
|------|----------------|
| 水道修理 | 水道工事店 |
| 電気修理 | 電気工事店 |
| ガス対応 | ガス会社・ガス器具修理 |
| エアコン修理 | エアコン専門店 |
| 鍵交換 | 鍵屋 |
| クロス張替え | 内装業者 |
| 床補修 | 床工事業者 |
| クリーニング | ハウスクリーニング |
| 警備・防犯 | 警備会社 |
| 排水管清掃 | 排水管洗浄業者 |

## 業者選定の基準

- 対応スピード（特に緊急時）
- 品質と保証
- 単価の透明性
- 請求書フォーマットの分かりやすさ
- スタッフの言葉遣い・身だしなみ
- 写真付き報告の有無
- 既存物件での実績

複数業者と取引することで、繁忙期のリスク分散・単価交渉力を確保できます。

## 業者との関係構築

- 月次定期発注で関係性維持
- 急な発注時の優先対応依頼
- 単価の年次見直し交渉
- 業者からの提案受け入れ
- 支払いの遅延禁止（業者の協力を引き出すため）

業者を「下請け」ではなく「パートナー」として扱う姿勢が、長期的な対応力に直結します。

## 大家・管理会社の実務ポイント

- 業者リストを業務分野別に整備
- 担当者名・連絡先・対応エリアを記録
- 発注実績・支払額の集計
- 業者ごとの評価（5段階等）
- 問題発生時の代替業者の確保
- 業者間の競争入札（年に数回）
- 賃貸管理ソフトで業者発注を一元管理
- 業者を介した修繕提案を継続的に受ける
