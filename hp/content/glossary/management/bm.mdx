## BMの主な業務

- 共用部清掃（日常・定期）
- 設備点検（電気・給排水・空調・消防）
- 法定点検の代行
- 害虫害獣駆除
- 植栽管理
- 警備
- ゴミ収集対応

これらを総合的に行うのが「総合ビルメン」、清掃のみ・設備のみといった専門特化型もあります。

## BMの委託形態

- 一括委託: 1社に全業務を委託
- 個別委託: 業務ごとに別会社に発注
- ハイブリッド: 一部一括＋一部個別

物件規模・予算・専門性で選びます。

## BM費用の相場

| 業務 | 費用相場 |
|------|----------|
| 共用部日常清掃（週1回） | 月1〜3万円 |
| 共用部定期清掃 | 1回1〜5万円 |
| 消防設備点検 | 半年1〜3万円 |
| エレベーター保守 | 月3〜10万円 |
| 受水槽清掃 | 1回5〜15万円 |

これらは物件規模・設備の数で大きく変わります。

## [PM](/glossary/pm)とBMの分担

PMは経営、BMは保守という役割分担です。

| 業務 | 担当 |
|------|------|
| 入居者対応 | PM |
| 修繕業者手配 | PM |
| 修繕工事の実施 | BM |
| 設備点検 | BM |
| クレーム対応 | PM |
| 異臭・故障の調査 | BM |

## 大家・管理会社の実務ポイント

- BMはPM経由で発注する物件が多い
- BM業者と直接契約する場合、PMとの情報共有体制を構築
- BM費用は[管理委託](/glossary/property-management)料に含まれないことが多い
- 法定点検の報告義務違反は罰金対象なので、確実に管理
- 大型物件はBM契約を分散させてリスク管理
- BM業者の質が物件の品質・入居率に直結
