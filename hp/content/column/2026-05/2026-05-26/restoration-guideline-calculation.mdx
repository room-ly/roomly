## 原状回復費用、どうやって計算していますか？

退去精算で最もトラブルになるのが、原状回復費用の金額です。入居者から「高すぎる」と言われたとき、根拠を示せるかどうかで対応が180度変わります。

国土交通省の「原状回復をめぐるトラブルとガイドライン」は、原状回復費用の計算方法について具体的な指針を示しています。このガイドラインに沿って計算すれば、入居者にも説明しやすく、トラブルに発展しにくくなります。

## 原状回復の基本原則

まず前提として、原状回復は「入居前の状態に戻すこと」ではありません。

ガイドラインでは、原状回復を以下のように定義しています。

> 賃借人の居住、使用により発生した建物価値の減少のうち、賃借人の故意・過失、善管注意義務違反、その他通常の使用を超えるような使用による損耗・毀損を復旧すること

つまり、**通常の使用で生じる損耗（通常損耗）と経年変化は貸主負担**、**入居者の故意・過失による損耗は借主負担**です。

## 負担区分の判定フロー

損耗を発見したら、以下の順で負担区分を判定します。

```
損耗を発見
  ↓
通常の使用で生じるものか？
  ├─ YES → 貸主負担（通常損耗・経年変化）
  └─ NO → 借主の故意・過失か？
       ├─ YES → 借主負担（ただし経過年数で減額）
       └─ NO → 貸主負担
```

### 通常損耗の例（貸主負担）

- 家具の設置による床のへこみ
- 日照による壁紙の変色
- テレビ裏の黒ずみ（電気ヤケ）
- 画鋲程度の壁の穴
- 鍵の自然劣化

### 故意・過失の例（借主負担）

- タバコのヤニ汚れ・焦げ跡
- ペットによる傷・臭い
- 結露を放置したカビ
- 引っ越し時の傷
- 釘・ネジの大きな穴

## 経過年数による減額計算

借主負担と判定された場合でも、入居年数が長いほど設備の価値は下がっています。ガイドラインでは、設備ごとに耐用年数を定め、経過年数に応じて借主の負担割合を減額するよう求めています。

### 主な設備の耐用年数

| 設備 | 耐用年数 | 備考 |
|------|---------|------|
| クロス（壁紙） | 6年 | 残存価値1円まで定額法で減価 |
| カーペット | 6年 | 同上 |
| クッションフロア | 6年 | 同上 |
| エアコン | 6年 | 同上 |
| 便器・洗面台 | 15年 | 衛生陶器 |
| ユニットバス | 建物に準ずる | 設備一体型 |
| フローリング | 建物に準ずる | 部分補修は経過年数考慮しない |
| 畳表 | 消耗品 | 経過年数を考慮しない |
| 襖・障子 | 消耗品 | 同上 |

### 計算式

```
借主負担額 = 修繕費用 ×（1 − 経過年数 ÷ 耐用年数）
```

ただし、**経過年数が耐用年数を超えている場合は、残存価値1円**です。

### 計算例

**ケース1：入居3年、クロス張替え**

- 修繕費用：¥54,000（¥1,200/㎡ × 45㎡）
- 耐用年数：6年
- 経過年数：3年
- 借主負担率：1 −（3 ÷ 6）= 50%
- 借主負担額：¥54,000 × 50% = **¥27,000**

**ケース2：入居7年、クロス張替え**

- 修繕費用：¥54,000
- 耐用年数：6年
- 経過年数：7年（耐用年数超過）
- 借主負担額：**¥1**（残存価値）

**ケース3：入居4年、クッションフロア張替え**

- 修繕費用：¥36,000（¥3,000/㎡ × 12㎡）
- 耐用年数：6年
- 経過年数：4年
- 借主負担率：1 −（4 ÷ 6）= 33.3%
- 借主負担額：¥36,000 × 33.3% = **¥12,000**

**ケース4：入居5年、フローリングの部分補修**

- 修繕費用：¥25,000
- フローリングの部分補修は経過年数を考慮しない
- 借主負担額：**¥25,000**

## 面積按分の考え方

クロスの張替えで部屋全体を張り替える場合でも、**借主負担は損耗が発生した箇所のみ**が原則です。

ただし、色合わせのために壁一面を張り替える必要がある場合は、**最低単位を「壁一面」とすることが妥当**とガイドラインは示しています。

つまり、タバコのヤニ汚れがリビングの一面にある場合、部屋全体の張替え費用ではなく、その一面分の費用を借主負担とするのが適切です。

## ハウスクリーニング特約の扱い

ハウスクリーニング費用を借主負担とする特約は、以下の条件を満たす場合に有効とされています。

1. **特約の必要性があり、暴利的でないこと**
2. **借主が特約の内容を理解していること**
3. **借主が特約による義務負担を認識していること**
4. **借主が特約を合意の上で契約していること**

金額が契約書・重要事項説明書に明記されていない場合や、退去時に初めて金額を提示する場合は、特約が無効とされるリスクがあります。

## 管理会社として注意すべきこと

### 見積もりは必ず明細を出す

「原状回復費用一式 ¥150,000」ではなく、箇所ごとの単価×数量を記載した明細を出してください。一式見積もりは入居者の不信感を招きます。精算書のフォーマットについては「[退去精算書の作り方](/column/move-out-settlement-template)」でテンプレートを紹介しています。

### 写真を撮る

退去立会い時に損耗箇所の写真を撮り、精算書に添付します。「この傷は最初からあった」と言われたときに、入居時の写真と比較できると強いです。

### ガイドラインは法的拘束力がない

国交省ガイドラインはあくまで指針であり、法的拘束力はありません。ただし、裁判になった場合にガイドラインに沿っているかどうかが判断基準として参照されるため、実質的にはこれに従うのが安全です。

## まとめ

原状回復費用の計算は、「負担区分の判定 → 経過年数による減額 → 面積按分」の3ステップです。

国交省ガイドラインに沿った計算をしていれば、入居者に対して根拠を示せますし、万一トラブルになっても管理会社としての立場を守れます。退去精算のたびに計算方法を調べ直すのではなく、自社の精算基準として標準化しておくことをお勧めします。
