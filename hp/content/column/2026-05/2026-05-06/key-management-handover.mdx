## 鍵の管理、どこまでルール化していますか？

賃貸物件の鍵は、管理会社が最も頻繁に扱う「物」の一つです。入居時の引き渡し、退去時の回収、内見時の貸し出し、紛失時の交換対応——日常業務の中で鍵に触れる場面は多いですが、管理ルールが曖昧なまま運用している管理会社は少なくありません。

鍵の紛失や受け渡しミスは、不法侵入のリスクに直結します。この記事では、賃貸物件の鍵管理と受け渡しの手順を整理します。

## 鍵の保管ルール

### 管理会社が保管する鍵

管理会社は通常、以下の鍵を保管しています。

| 鍵の種類 | 用途 |
|---------|------|
| マスターキー | 共用部（エントランス、ゴミ置場、PS） |
| 各戸のスペアキー | 緊急時の入室（水漏れ、安否確認） |
| 空室の鍵 | 内見対応 |
| 倉庫・設備室の鍵 | 設備点検・清掃 |

### 保管方法

- **鍵管理ボックス（キーキャビネット）** を使い、番号で管理する
- 鍵と物件を紐づける台帳（鍵管理台帳）を作成する
- 鍵には物件名・部屋番号を直接記載しない（紛失時のリスク軽減）
- 鍵の持ち出し・返却は台帳に記録する（日時・担当者・目的）
- 保管場所は施錠できるスペースに限定する

鍵に「○○マンション 101号室」と書いたタグをつけて保管している管理会社がありますが、万が一鍵を紛失した場合に物件が特定されるリスクがあります。物件コード（P001-101など）で管理してください。

## 入居時の鍵の引き渡し

### 引き渡し前の確認

- 鍵の本数（契約書記載の本数と一致しているか）
- 鍵の種類（ディンプルキー、ディスクシリンダー等）
- 全ての鍵が正常に動作するか（引き渡し前に施解錠の確認）
- 前入居者の鍵が残っていないか（鍵交換済みの確認）

### 引き渡し時の記録

- 引き渡した鍵の本数・種類を書面に記録する
- 入居者の受領サインをもらう
- 「合鍵の作成は事前に連絡」「紛失時は速やかに連絡」を口頭でも説明する

### 鍵交換のタイミング

前入居者が合鍵を作成している可能性があるため、**退去ごとに鍵を交換するのが原則**です。国土交通省のガイドラインでは、鍵交換費用は原則としてオーナー負担ですが、特約で入居者負担とするケースも一般的です。

## 退去時の鍵の回収

### 回収の確認項目

- 入居時に引き渡した本数と一致しているか
- 合鍵を作成していた場合、その分も回収
- 鍵の状態に問題がないか（曲がり、破損）

### 本数が足りない場合

入居者が紛失している場合は、鍵交換の費用を入居者に請求します。退去精算の項目として処理するのが一般的です。退去精算の詳細は「[退去精算書の作り方](/column/move-out-settlement-template)」を参照してください。

## 鍵紛失時の対応

### 入居者が紛失した場合

1. 入居者から管理会社に連絡
2. スペアキーの有無を確認（管理会社保管分）
3. 一時的にスペアキーで対応（入居者への貸し出し）
4. 鍵交換の手配（防犯上、シリンダーごと交換が望ましい）
5. 費用の請求（入居者負担）

### 費用の目安

| 鍵の種類 | 交換費用の目安 |
|---------|--------------|
| ディスクシリンダー | ¥10,000〜¥15,000 |
| ディンプルキー | ¥15,000〜¥25,000 |
| カードキー・電子錠 | ¥20,000〜¥40,000 |

### 管理会社が紛失した場合

管理会社の過失で鍵を紛失した場合は、管理会社の費用負担で鍵交換を行います。オーナーへの報告と入居者への謝罪が必要です。

## 内見時の鍵の取り扱い

### キーボックスの利用

空室の内見対応では、物件にキーボックスを設置して仲介業者が鍵を取り出す方式が一般的です。

注意点：
- キーボックスの暗証番号は定期的に変更する
- 内見後の施錠確認を仲介業者に依頼する
- 入居が決まったらキーボックスを撤去する

### スマートロックの活用

最近は、内見用にスマートロックを導入する管理会社も増えています。時間限定のワンタイムキーを発行できるため、鍵の受け渡しが不要になります。

## 鍵管理台帳の項目

| 項目 | 内容 |
|------|------|
| 物件コード | P001 |
| 部屋番号 | 101 |
| 鍵の種類 | ディンプルキー |
| 保管本数 | 2本 |
| 引渡本数 | 2本（入居者）+ 1本（管理会社保管） |
| 鍵番号 | メーカーの刻印番号 |
| 最終交換日 | 2026-03-15 |
| 備考 | 前回交換時にシリンダーごと交換 |

## まとめ

鍵管理は「保管 → 引き渡し → 回収 → 紛失対応」の4つの場面でルールを決めておけば、トラブルを防げます。

鍵には物件名を直接記載せずコードで管理すること、退去ごとに鍵交換を行うこと、持ち出し・返却を記録すること——この3つを徹底するだけで、防犯リスクは大幅に下がります。
